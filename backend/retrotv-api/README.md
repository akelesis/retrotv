# RetroTV API (NestJS + TypeScript)

Quick start:

1. Install dependencies

```powershell
cd "c:\Users\marcu\OneDrive\Desktop\Projetos\Retro TV\backend\retrotv-api"
npm install
```

2. Run in dev mode

```powershell
npm run start:dev
```

App will listen on http://localhost:3000. Files created: [package.json](package.json), [tsconfig.json](tsconfig.json), [src/main.ts](src/main.ts)
